# Security policy

This repository contains **recordings and detection rules**, not exploits. Every scenario uses a
harmless payload: the agents are never logged in, and the only prompt used is
"Reply with the single word OK."

## Reporting

If you find a security problem in this repository (for example, a recording that leaks
something it should not, or a rule that can be abused), please report it privately through
GitHub's **Report a vulnerability** button on the Security tab. Please do not open a public issue.

If you believe you have found a vulnerability in an AI coding agent itself, report it to that
vendor (Anthropic or OpenAI) through their disclosure programme, not here.
